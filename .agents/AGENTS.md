# KBSV NextGen 2026 — Agent Rules

## Project Identity
- **Tên dự án:** KBSV NextGen 2026 (Chương trình Tuyển dụng – Đào tạo – Thực chiến Môi giới Thế hệ mới)
- **Đơn vị:** Sở Giao dịch 3 (HO3) — KB Securities Vietnam
- **Đối tác:** FinPeace

## Brand Rules
- **Bảng màu chính:** Yellow `#F5A623`, Brown `#8B7355`, Warm Background `#FAFAF7`
- **Typography:** `Space Grotesk` (Display), `Inter` (Body)
- **Logo format:** "KBSV NextGen 2026 · FinPeace × KB Securities Vietnam"
- **Tone of voice:** Chuyên nghiệp nhưng gần gũi Gen Z, truyền cảm hứng, thực chiến

## Content Rules
- Tất cả nội dung đào tạo phải theo framework 42 ngày (2 tuần học + 4 tuần thực chiến)
- Module đào tạo: 1500+ từ, bao gồm bài đọc + bài tập + interactive + test + role-play
- Phiếu đánh giá phỏng vấn: khung ASK (Attitude 50% > Skills 40% > Knowledge 10%)
- Tiêu chuẩn tuyển dụng: ưu tiên Thái Độ & Growth Mindset hơn kinh nghiệm

## Fixed Parameters (Không thay đổi)
- Ngân sách: 20.000.000 VNĐ
- Giải nhất: 5.000.000 VNĐ
- Thưởng active TK: 50k-200k/TK
- Daily Routine: Morning Briefing → Content Lab → Livestream 90'
- Quy tắc Sudden Death: Áp dụng từ Tuần 3
- Trainer/Mentor: Quân, Yến, Tuấn Anh, Quang, Vinh + Research team

## File Conventions
- Tài liệu in PDF: file HTML print-only (không JS interactive, không localhost link)
- Web pages: match branding `nextgen.finpeace.cloud`
- Mã mẫu tài liệu: `NTD-SV-XX` (tuyển dụng), `PV-SV-XX` (phỏng vấn), `DT-XX` (đào tạo)
